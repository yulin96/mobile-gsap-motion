# 场景验收

用于维护 skill 时检查指令是否导向合适的决策。下表是验收标准，不是已运行的页面测试；实际验证依据当前项目约定执行。

| 用户请求 / 工程条件 | 预期行为 | 需要识别的偏差 |
| --- | --- | --- |
| “优化整体动画，部分元素有创意一点”；已有默认路由动画 | 沿用路由效果，优化页面内部层次，按素材挑选少量细节 | 擅自加入全局缩放或共享元素转场 |
| “添加 H5 入场动画”；项目没有路由动画 | 按内容安排入场，保留当前导航方式 | 把缺少转场视为必须新增转场 |
| “这个返回要缩回菜单卡片，里面的元素依次消失” | 读取现有返回 hook、CSS 和缓存逻辑，为指定返回路径适配，统一完成信号并处理取消 | 改成所有页面统一缩回；路由层和内容层抢同一变换 |
| “滚动然后出现动画可以先去掉，默认可以连续都展示了” | 移除相关滚动门槛，将内容和地图内部层次接进入场 timeline | 保留 observer 门槛；直接删除全部动画 |
| “逐行随滚动出现，快速滚动也不能插队” | 观察稳定外层与真实滚动容器，统一队列，补齐跳过的行，参数联动 | 每批 stagger 从零开始；误用连续入场替代明确要求 |
| “动画幅度大点”；随后说“太慢了，再快点”，又说“取中间值” | 分开收敛行程、落定时长与起点间隔，保留不同页面的节奏关系，检查累计等待及裁切 | 只改全局 timeScale；固定沿用历史项目的秒数或曲线 |
| “间隔有时要短，有时要长，卡片像逐张贴上去” | 根据组内、换排、主次与层级安排不等起点，检查最后一项出现时间 | 每项统一等待前一项完全结束；密集列表越排越慢 |
| “出现有动画，关闭就是闪，蒙层也一样” | 核对节点隐藏时机与组件库过渡，内层从当前状态退出，外层与遮罩同步淡出 | 立即 v-if 卸载或设 autoAlpha 为零；遮罩先消失 |
| “弹窗刚打开就关闭，再马上打开” | 取消本轮入场与过期异步开场，重开终止旧退场，稳定显示状态决定可见性 | 旧回调重新显示已关闭弹窗，或关闭新一轮弹窗 |
| “去掉点击后像被按下的倾斜，换位时加回弹” | 移除内部按压 tween，布局层使用平顺行程与回弹，透明度另用无弹性曲线 | 把去掉倾斜理解为去掉全部换位；加回弹时又恢复内部倾斜 |
| “取消点击小卡切换”；之后又明确要求恢复 | 各次按最新指示同步热区、事件与读屏提示，保留当次仍需的箭头、横滑及主卡导航 | 把过去禁用点击固化为全局技能规则，或借调动画擅自改交互 |
| “点击相隔两格的卡片，连续换过去，不要中途停” | 预先计算业务路径，途经槽位作为关键帧，行程连续、最终统一回弹，业务活动项设为最终目标 | 逐格新建缓动并回弹，或途经卡位依次启动装饰循环 |
| 卡片缩小时图片轻抖、canvas 分辨率变化 | 核对父卡尺寸、百分比子素材与 object-fit，采用稳定绘制尺寸及独立 layout 变换层 | 只换 easing；让 canvas 继续逐帧重设分辨率 |
| 缓存返回后布局缩放为 NaN，隐藏时尺寸为零 | 无效观察期间保留最近有效尺寸，恢复后重排并处理动画中断和交互锁 | 将 0 / 0 写入缩放缓存；靠重播整页入场掩盖 |
| “不再是大卡后也要播完本轮再停” | 播至末帧后显式暂停，处理末帧、重新激活和缓存尾段，导航照原时机执行 | 切换开始就冻结；所有小卡自动播放；等待尾段才能进入页面 |
| “标题大点、尽量等高，这个三行的可以更高” | 核对图片比例，放宽长标题区域并约束同组高度，多行单独保留块高 | 统一窄宽度导致长标题更小；拉伸或裁切多行文字 |
| 子面板缩略图提前播完，页脚或地图循环等待过久 | 用父面板可见标签和对应片段真实完成标签衔接，循环不参与入场完成时长 | 子元素都从页面零时刻开始；后续依赖整页最大时长 |
| “只分析闪烁，不改代码” | 定位初始 CSS、from/fromTo、clearProps、生命周期和转场交接，给出证据 | 顺手修代码；静态检查后声称播放正常 |
| “用新导出的标题图做逐行动画” | 核对新图尺寸、行范围和间距，按实际素材裁切 | 直接搬用旧图坐标或把图片当可拆分 DOM 文字 |
| “本次不做浏览器测试”或项目要求明确授权后才测 | 按允许范围做代码或文档检查，说明实际验证边界 | 因技能验收清单擅自启动浏览器或另加测试流程 |

复查新指令是否与现有章节、参考代码或默认调用提示冲突。代码格式与静态检查通过，只证明对应检查通过；首帧、衔接和缓存返回的实际播放结论需要允许范围内的浏览器观察，真实触摸与设备性能仍需相应设备验证。看终态截图不能证明退出连续、回弹发生或序列帧已播完。
